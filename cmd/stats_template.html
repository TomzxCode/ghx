Author × reviewer matrix

Each cell counts the PRs authored by the row author that the column reviewer responded to, with the share of that author's PRs the reviewer responded to (cell count divided by the row Total), and the average and median time from PR creation to that reviewer's first response. A response is an issue comment or a submitted review (approval, change request or review comment). Because a PR can have several reviewers, a row's shares can add up to more than 100%. The (no reviews) column counts PRs no reviewer responded to. Reviewers exclude the PR author{{if not .IncludeBots}} and bot accounts{{end}}.
